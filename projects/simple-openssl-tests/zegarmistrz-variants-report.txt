=== NATIVE CONTROLS

Native runs with no emulator involved, one per flavor, via
./run_all.sh --poison-all --poison-variants=all:

  zunsafe flavor:   80/80 PASS
  sarcastic flavor: 80/80 PASS

Outside the zegarmistrz emulator the poisoning service calls are no-ops,
so poison options never change program behavior: every (poison option,
variant) combination must pass natively, and both flavors do.
