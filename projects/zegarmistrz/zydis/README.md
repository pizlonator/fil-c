# Vendored Zydis (amalgamated distribution)

This directory is the **amalgamated Zydis v4.1.0 distribution**, vendored so
the emulator does not depend on system Zydis packages. Upstream's amalgamation
inlines the entire public API of Zydis **and** Zycore into the two
distribution files, so this is the whole decoder — nothing else to install:

- `Zydis.h` — the entire public API: Zydis declarations with Zycore inlined.
- `Zydis.c` — the entire implementation: Zydis plus the Zycore runtime.
- `LICENSE-Zydis`, `LICENSE-Zycore` — the MIT licenses of the two upstream
  repos, [zyantific/zydis](https://github.com/zyantific/zydis) and
  [zyantific/zycore-c](https://github.com/zyantific/zycore-c).

## Provenance

Downloaded verbatim from upstream:

```
https://github.com/zyantific/zydis/releases/download/v4.1.0/zydis-amalgamated.tar.gz
sha256 aa9b82be3a37a2998bd8e16cf583bbf2b6c3d80e97dc20504169dc32ca1ced59
```

`Zydis.h` and `Zydis.c` are **auto-generated by upstream's
`assets/amalgamate.py`** — never hand-edit them. To update Zydis, download the
new amalgamated tarball and replace both files (plus the license files)
wholesale; the Makefile needs no other change.

## How it builds

`make` (in the parent directory) compiles `Zydis.c` into `zydis/Zydis.o` as
part of the normal build:

```
$(CC) $(CFLAGS) -Izydis -DZYDIS_STATIC_BUILD -DZYCORE_STATIC_BUILD -c -o zydis/Zydis.o zydis/Zydis.c
```

`ZYDIS_STATIC_BUILD` and `ZYCORE_STATIC_BUILD` are the documented defines for
using the amalgamation statically, and `-Izydis` is what makes the emulator's
`#include <Zydis.h>` resolve to the amalgam header (see
`src/decode_exec.cpp`).

## Why vendored

Distro Zydis packages are often too old for the v4 API the emulator uses (the
3-argument `ZydisDecoderInit`, `ZydisDecoderDecodeFull`, ...), which broke the
build on systems shipping older Zydis. Vendoring the amalgamation removes the
system `libzydis-dev`/`libzycore-dev` dependency entirely: no `-lZydis` or
`-lZycore` on the link line (Zycore is inlined into `Zydis.o`), and the
decoder version is pinned to one this project's source is written against.
